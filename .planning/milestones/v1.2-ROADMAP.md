## Milestone Summary

**Decimal Phases:** None.

**Key Decisions:**

- Real Hive (temp dir) over fake repositories for integration tests — the "integration" phase should exercise the real persistence layer, not re-verify BLoC logic already covered by unit tests. ✓ Validated.
- `LiveTestWidgetsFlutterBinding()` for tests with real Hive writes — `TestWidgetsFlutterBinding.ensureInitialized()` hangs forever on real `dart:io` Hive writes inside `testWidgets`. ✓ Validated.
- Hand-rolled PDF text extraction (zlib + Tj/TJ regex) over a new package — no suitable pure-Dart, FFI-free PDF text-extraction package exists on pub.dev. ✓ Validated.
- CRUD flows driven by real widget taps only (D-01), stats proven via visible UI (D-03) — integration tests assert what the user sees, not internal state. ✓ Validated.
